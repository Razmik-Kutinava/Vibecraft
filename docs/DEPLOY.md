# Деплой Vibecraft.su

Сборка — статический сайт в `dist/` (`npm run build`). Продакшен можно вести несколькими способами; сейчас основной сценарий — **Vercel** от GitHub.

---

## Vercel (текущий рабочий процесс)

1. Репозиторий подключён к проекту Vercel; пуш в `main` триггерит **Production**-деплой.
2. В корне лежит **`vercel.json`**: пресет `astro`, команда сборки `npm run build`, выход **`dist/`**, редирект **`/favicon.ico` → `/favicon.png`**. Поле **`trailingSlash`** намеренно не задано: на Vercel значение `true` ломало бы запросы к файлам с расширением (браузер тянет `/favicon.ico`, получалась цепочка со слэшем и **403**).
3. **Переменные окружения** (Dashboard → проект → **Settings → Environment Variables → Production**):
   - **`PUBLIC_SITE_URL`** — публичный URL **без** слэша в конце (`https://vibecraft.su` или ваш кастомный домен на Vercel). Нужны для `@astrojs/sitemap` и canonical в шаблонах. Допускается только домен без схемы (`vibecraft.su`) — при сборке к нему добавляется `https://`.
   - **`PUBLIC_GOOGLE_FORM_URL`** (опционально) — полная ссылка на форму Google (`https://forms.gle/...` или публичный URL формы).
4. После успешного деплоя проверить в браузере **`/sitemap-index.xml`** (все ли URL на нужном домене). При смене основного домена обновить строку **`Sitemap:`** в **`public/robots.txt`**, если она указывает на старый хост.

### Техническая защита от падения сборки по `site`

В **`astro.config.mjs`** URL для поля **`site`** нормализуется: обрезаются пробелы, при отсутствии схемы добавляется `https://`, при невалидном **`PUBLIC_SITE_URL`** на сборке используется автоматический **`VERCEL_URL`**, затем запасной `https://vibecraft.su`. После этого в **`process.env.PUBLIC_SITE_URL`** подставляется уже согласованное значение, чтобы не расходился конфиг Astro и разметка страниц.

## Статика вручную / другой хостинг

1. Задать **`PUBLIC_SITE_URL`** в `.env` или в CI на URL продакшена.
2. Выполнить **`npm run build`**.
3. Залить содержимое **`dist/`** на хостинг (SFTP, rsync, объектное хранилище + CDN и т.д.). В репозитории ранее встречался сценарий с **`deploy.sh`** и ISPManager по SSH — это отдельный путь, не связанный с Vercel.

- Исправлена ошибка билда **`site: Invalid url`** на Vercel из‑за кривого **`PUBLIC_SITE_URL`**: в **`astro.config.mjs`** добавлена нормализация origin и fallback на **`VERCEL_URL`** / дефолтный домен.

- Изменения закоммичены и отправлены в **`origin/main`**, чтобы Vercel подхватывал их автодеплоем.
- **403 на `/favicon.ico`**: в **`vercel.json`** убран **`trailingSlash: true`** (иначе браузерный запрос к файлу с расширением мог превращаться в путь со слэшем и отдавать 403); добавлен редирект **`/favicon.ico` → `/favicon.png`**, в **`Layout.astro`** — явный **`shortcut icon`** на PNG.
